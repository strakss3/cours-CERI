# cours-CERI

This repository gathers all my coursework, labs, exercises, and projects completed at CERI (Centre d'Enseignement et de Recherche en Informatique), University of Avignon, as part of my **CMI Computer Science** program.

## Repository structure

The repo is organized by academic year/level:

```
cours-CERI/
├── L1/     # Year 1
├── L2/     # Year 2
└── CMI/    # CMI-specific modules
```

Each folder contains lecture materials, exercises, labs, and projects sorted by subject (algorithms, networking, web development, systems, etc.).

## Purpose

Centralize my university work to:
- Keep track of my progress
- Make it easier to revise and reuse code/notes
- Share my work with other CERI students
